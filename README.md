# Playful Pup & Bunny (Respectful Content)

Important: I cannot create content that depicts graphic violence or animal harm. Your original request described graphic violence toward a rabbit, which I cannot produce. Instead, this project scaffold targets a friendly, kid-safe game where a little dog plays and befriends a bunny — a playful tug-of-war / rescue-style mini-game with no graphic harm.

Project overview
- Title: Playful Pup & Bunny
- Concept: A charming, family-friendly microgame where the dog interacts with a rabbit through playful mechanics (fetch, tug-of-war as a cooperative mini-game, rescue nudges). No graphic violence.

Tech
- Vite + React + TypeScript
- ESLint + TypeScript rules

Getting started
1. Install: npm install
2. Dev server: npm run dev
3. Build: npm run build
4. Preview production build: npm run preview
